# AVIO Storefront\n\nFull-stack service commerce website built with Next.js App Router and Supabase (Postgres + Auth + Row Level Security). Deploy on Vercel for a hosted subdomain.\n\n## Setup\n1. Install Node.js 20+.\n2. `npm install`\n3. Copy `.env.example` to `.env.local` and set Supabase project URL and publishable key. Keep the service-role key server-only.\n4. Apply `supabase/migrations/001_store.sql` to your Supabase project.\n5. `npm run dev`\n\n## Deployment\nImport this GitHub repository into Vercel, set the environment variables, and deploy. The Vercel project provides a `*.vercel.app` subdomain; connect a custom domain later if desired.\n\n## Important\nThe initial `index.html` was a visual/browser-only prototype. This repository is being migrated to this server-backed Next.js app. Payment references are manually verified; this is not an automatic payment gateway. Never store secret keys in frontend code.\n
